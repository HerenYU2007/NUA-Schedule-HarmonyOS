# 南艺电子课表 · HarmonyOS 原生版

原生 ArkTS / ArkUI / ArkWeb / Form Kit 实现，以 Android 教务版 **1.2.4** 的现有功能为迁移基准。非南京艺术学院官方应用；与安卓和鸿蒙个人版分别维护。

当前鸿蒙版本仍为 **1.2.2 / 1002002**；Bundle 为 `cn.nua.wenguan.schedule`，最低 HarmonyOS 6.0 / API20。

[源码与测试安装包](https://github.com/HerenYU2007/NUA-Schedule-HarmonyOS/releases/tag/v1.2.2)。带 `debug-signed` 的 HAP 仅供已授权调试设备使用；未签名 HAP 需要自行签名，均不是正式商店发布包。

## 功能

- 日程、课表、我的三页；列表 / 竖条模式、原生连续滑动切周、具体日期选择、顶部课程详情。
- 点击课程只编辑对应时段；颜色、学分、备注、周次 / 单双周、自定义时间、复制和删除。
- 竖条空白位置建课；拖动移动、上下边缘调整节数、再次点击详细编辑，点其他位置取消；有课程或日程的位置不重复建课。
- 个人日程进入周课表；冲突单列提示，重叠课程点开选择，不压缩成细条；日程列表始终以今天为基准。
- 下一节课倒计时；总开关、选定课程、整门课 / 单次提醒、通知 / 系统代理闹钟。
- 四种独立桌面卡片：今日列表、竖条周课表，各有深色和白色；附选择预览图。支持切日 / 切周、22点默认明天、隐藏结束课程、升级恢复及脱敏诊断。
- 学校官方桌面登录页，自动放大登录区域；登录后进入教务导出 XLS，内外网通道重试及同会话恢复。新获取才清登录，启动不弹登录，不保持账号或后台刷课表。
- 失败时手动导入 XLS；首次导入选择开学日期；变更记录和仅“有课表更新”的通知。
- JSON 备份恢复、真实二进制 XLS 表格、ICS 日历；兼容安卓课程备份。恢复前预览，取消不覆盖，失败回滚。
- 主题、简洁设置、调试开关、南艺元素图标、上午新节次时间。
- 仅打开应用或手动检查软件更新；市场与多个公共元数据站点并行，旧结果不提前结束，手动无更新时提示。

## 鸿蒙系统边界

- **安装更新**：正式市场分发使用 AppGalleryKit 系统更新接口。GitHub / 镜像仅提供更新提示与官方发布页，不能把安卓 APK 或任意调试 HAP 当成鸿蒙安装包；没有绕过签名或静默安装。
- **卡片**：使用原生文字与布局，不把课表压成低清位图。实际刷新由系统管理，不保证每分钟或22点整点立即执行。卡片切换使用按钮。
- **提醒**：系统代理最近30条未来事项，打开 / 导入 / 编辑时补充。省电、权限、关闭应用时间过长可能影响后续补充；不使用系统专用 ACL。
- **登录**：只在学校页面输入密码，不读取密码、不代填验证码。不同学校认证域可能仍需重新认证；不会绕过 HTTPS 证书校验。
- **验证**：编译和纯逻辑测试通过，不等于所有机型触摸、桌面卡片和通知均通过。逐项真机状态见 MIGRATION-ANDROID-1.2.4.md。

## 构建

```powershell
.\Build.ps1
& 'E:\HarmonyDev\tools\node-v24.16.0-win-x64\node.exe' tools/validate.cjs
& 'E:\HarmonyDev\tools\node-v24.16.0-win-x64\node.exe' tools/parity-tests.cjs
& 'E:\HarmonyDev\tools\node-v24.16.0-win-x64\node.exe' tools/migration-tests.cjs
& 'E:\HarmonyDev\tools\node-v24.16.0-win-x64\node.exe' tools/update-race-tests.cjs
.\BuildDelivery.ps1
```

工程、工具缓存、备份、交付均在 E 盘。HAP 在 `entry/build/default/outputs/default/`；签名调试包只对 Profile 授权的设备可用，不是正式上架包。

源码交付排除私钥、证书、Profile、机器签名配置、账号配置、真实课表、缓存和编译产物。首次构建从未签名模板复制配置，再在自己的 DevEco Studio 配置对应应用签名。本机已有签名配置不覆盖。

## 安全与许可

学校下载逐跳检查 HTTPS 和允许的教务路径，WebVPN 绑定当前路由。诊断不含密码、Cookie、票据或网页正文。更新镜像不接收学校会话。备份仅含课程、日程和偏好。
